# Fonts

[Sarabun](https://github.com/cadsondemak/Sarabun) (Thai and Latin subsets, weights 400, 600, and
700), from the [`@fontsource/sarabun`](https://www.npmjs.com/package/@fontsource/sarabun) package,
version 5.3.0. `src/render.tsx` embeds these files in `results.svg`, because an SVG in an `<img>`
cannot load web fonts.
