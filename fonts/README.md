# Fonts

[Sarabun](https://github.com/cadsondemak/Sarabun) (Thai and Latin subsets, weights 400, 600, and
700), from the [`@fontsource/sarabun`](https://www.npmjs.com/package/@fontsource/sarabun) package,
version 5.3.0. `src/render.tsx` embeds these files in `results.svg`, because an SVG in an `<img>`
cannot load web fonts.

See [OFL.txt](OFL.txt).

[TASA Orbiter](https://github.com/localremotetw/TASA-Typeface-Collection) (Latin subset, weights
400–800), from the
[`@fontsource/tasa-orbiter`](https://www.npmjs.com/package/@fontsource/tasa-orbiter) package,
version 5.3.0. The slides (`src/slides.tsx`) use it for English text.

Copyright 2022-2025 The TASA Typeface Collection Project Authors. Licensed under the SIL Open Font
License, Version 1.1. See [OFL-tasa-orbiter.txt](OFL-tasa-orbiter.txt).
